PV GROUPS WEBSITE

To open the website:
1. Make sure Node.js is installed.
2. Double-click OPEN_WEBSITE.bat.
3. The first time, it will install the required packages automatically.
4. Chrome will open the website automatically.

Do not double-click index.html for this React/Vite project.

To stop the website, close the command window that was opened by OPEN_WEBSITE.bat.
